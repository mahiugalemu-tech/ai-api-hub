# Universal AI API Hub — PRJ-08

Starter project for the Universal AI API Connector & API Hub assignment.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Planned modules

- Admin dashboard
- Connector configuration
- Gemini + Groq provider adapters
- Dynamic input fields
- Prompt engine
- Structured JSON output
- Generated API endpoints
- Automatic API documentation
- API testing playground
- Usage statistics and logging
- Authentication and security
- Public deployment
